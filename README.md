## Project Description
Our project is an AI Model that predicts fair market prices for used items by analyzing online marketplace data, in our case its ebay. It addresses pricing inconsistency by using machine learning to evaluate factors such as product condition, age, and model. The system features a data pipeline for real-time scraping and an ensemble of algorithms to provide accurate price ranges and confidence scores. It can benefit the both individual sellers and buyers by offering data-driven recommendations to maximize revenue and prevent overpayment. The project has a scalable technical architecture and a roadmap to expand into web applications and additional product categories.
