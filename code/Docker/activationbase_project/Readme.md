## Data Description
- **File**: activation_data.csv
- **Purpose**: Contains sample used product data for price prediction model activation
- **Format**: CSV with 5 columns
- **Features**: 
  - age_months: Product age in months
  - condition_score: Condition rating (1-10)
  - original_price: Original purchase price
  - current_price: Current market price (target variable)
- **Size**: 10 sample products
- **Source**: Simulated data for academic demonstration
